# Ola S1 Air contact page

Stellar Blue, RJ11 ST 3525. Scan the QR access link, then enter the number shown on the scooter. Includes owner Call, WhatsApp, SMS and the same emergency contact as the car.

Domain: myolas1air.tenguriya.com. Pages publishes main in TengoCharlie/ola-s1-air-contact. Scooter DNS needs Squarespace account verification.

Client-side access checks are not secure authentication. Copied QR URLs work with the registration number. Contact data remains in static source.
